# Security policy

## Supported versions

Security fixes are provided for the latest published release of Hargassner
Cloud. Update to the latest release before reporting a vulnerability.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting feature for this repository. Do not open a public issue
for a security problem.

Never include Hargassner passwords, access tokens, installation IDs, complete API
responses, or unredacted Home Assistant diagnostics in an issue, discussion, or
pull request.

Include only the minimum information needed to reproduce the issue. Redact email
addresses, tokens, installation identifiers, and other personal data from logs
and screenshots.

## Scope

This project is an independent Home Assistant custom integration. Security
problems in the Hargassner service itself should be reported directly to
Hargassner through an appropriate private channel.
